# AgroMarket

## Módulo Catálogo

Este proyecto corresponde al módulo de catálogo de productos agrícolas de la plataforma AgroMarket.

Permite visualizar productos, organizarlos por categorías y consultar precios referenciales.

El proyecto utiliza Git para el control de versiones, GitHub para la colaboración.
